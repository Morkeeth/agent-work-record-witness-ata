# TRANSCRIPTO — PRD (Aug 2026)

*The verification gate an autonomous workforce passes before its work counts.*

Grounded at the object: `contract/gate.py`, `contract/adjacency.py`,
`contract/deterministic.py`, `fleet/human.py`, `fleet/propagate.py`, `docs/COMPANY.md`,
`CONTEXT.md`. Numbers are file-cited or command-verified. Facts corpus:
`~/CODE/cleared/research-corpus/2026-08-24-prd-transcripto.md`.

Two docs describe two GTM stages of ONE product: COMPANY.md is the PR-blocking gate
(the wedge); CONTEXT.md is the fleet-management corpus (the record). `contract/gate.py`
now holds both axes in one call — that is the reconciliation this PRD is written around.

---

## 1 · One-liner + the pain

**One-liner.** Transcripto is the verification gate an autonomous workforce passes before
its work counts — one call that BLOCKS an agent's report when the report lies by
composition, and (optionally) tells you whose human prompt actually did the work.

**The pain (sell this, not the mechanism).** A company handed coding agents to hundreds of
engineers. Code is now 5–10× faster to write, so the bottleneck inverted: *verification
before merge is the constraint, not generation* (Qodo's own framing). Two failures leak
past everything already deployed:

- **The confident lie by composition.** An agent writes *"96% of projects have a phase on
  disk"* on the line above *"21 no repo · 1 unknown."* Every number is true. Sign it, hash
  it, attest it — each figure really happened. The report still says 96% where the truth is
  50%, because the denominator quietly dropped the cases named right beneath it. No
  per-claim attestation, no code review, no trace-scoring catches it — they check one claim
  or one diff, and this failure needs no false sentence (`contract/adjacency.py:1-61`).
- **Nobody can see practice.** The org can see seats and spend. It cannot see what any
  engineer typed, which prompt worked, or who is good at this. The best prompt for its
  codebase already exists — someone wrote it last Tuesday and no one else will ever see it.

The incidents wrote the budget: Replit deleted a prod DB; Amazon's Kiro tore down a
CloudFormation stack (`docs/COMPANY.md:26`). "Prove no agent shipped unverified" is now a
board-level line.

## 2 · The day-two buyer + the personal angle

**Day-two BUYER: whoever owns the AI rollout at an org running an agent workforce with a
governance budget** — VP Eng, Head of Platform, Head of Enablement (`CONTEXT.md:47`). Not
a solo dev. The reason is measured, not asserted: the authorship moat is a function of
FLEET SIZE (see §7). At one terminal ~46% of `type:user` turns are not the human; at fleet
scale it is 95.1%. The customer is the org whose injected traffic makes the signal exist.

**Day-one scope (honest):** an opt-in team corpus over Claude Code transcripts the org
indexes locally or uploads to Firestore — not "hundreds of seats" on submit day
(`CONTEXT.md:45`).

**The personal use (Oscar's own prompting).** The same corpus, pointed at one operator's
own logs, is a prompting coach: surface my best- and worst-performing prompt patterns from
what I actually typed, ranked by whether the work survived. This is the single-seat entry
point that needs no org buy-in and dogfoods the product — the propagation loop
(`fleet/propagate.py`) run against my own transcripts instead of the team's. It is also the
cheapest possible first user who is not a judge.

## 3 · What EXISTS vs what is claimed

Verified by running the code today (`pytest contract/ -q` → 17 passed).

**Exists and works:**
- **`verify_report()` — the single gate call** (`contract/gate.py`). COMPOSITION axis
  BLOCKS; TASK/AUTHORSHIP axis is optional and REPORTED, not gated (a task-class judgement
  is not a production-safety verdict — a deliberate, honest boundary).
- **Adjacency — FOUR shapes, not three** (`contract/adjacency.py`; the brief said three):
  DENOMINATOR-EXCLUDES-ITS-FAILURES, COUNT-DISAGREES-WITH-ITS-LIST, PARTS-DO-NOT-SUM,
  PERCENT-CONTRADICTED-BELOW (fourth added commit 5bb88ed).
- **The Twist fires** (command-verified, not asserted):
  `printf '22 of 23 ...\n21 no repo · 1 unknown\n' | python3 -m contract.gate` →
  `[BLOCK] DENOMINATOR-EXCLUDES-ITS-FAILURES`, exit 1.
- **The cascade** (`contract/deterministic.py`): a free offline classifier answers the
  cells it has evidence for and DEFERS to the LLM on exactly one provably-unique cell.
  Precision on the kept set 13/13, coverage 13/24 (~54%), held-out lift 5/8 vs 3/8 baseline
  (`prove_lift.py`, run today). This is patent ANGLE 1.
- **The authorship gate** (`fleet/human.py::is_human_turn`): `type==user` AND
  `promptSource in (typed,queued)` AND not isMeta/isSidechain AND `toolUseResult is None`.
  This is the 4.9%-vs-95.1% separator — the moat.
- **The propagation loop** (`fleet/propagate.py`): rank human prompts by outcome signal →
  write curated text to an org skill file → witness the file landed. Never executes
  transcript text.

**Claimed / not yet real:**
- Adjacency real-corpus precision is **measured and mostly noise** for two shapes and
  **unmeasured** for two (see §7). Do not claim it is "accurate."
- The prompting-coach surface (§6) is designed, not built.
- The GitHub Marketplace Action wedge exists as `gate/outcome_gate.py` +
  `.github/workflows/outcome-gate.yml` but has **zero installs by anyone who is not Oscar** —
  which COMPANY.md itself names as the only number that matters (`docs/COMPANY.md:40-42`).
- Cross-harness (Cursor/Copilot/Codex) transcript ingestion is expansion, not built.

## 4 · Wedge / white-space

**Composition-honesty is unowned.** The funded platform is real and adjacent but checks a
different object:
- **Zenity ($125M Series C, Aug 2026)** governs agent ACTIONS — allow/modify/block an
  agent's intent. It does not ask whether the agent's *report* is honestly composed.
- **Norm Ai ($120M Series C, $1.2B, Jul 2026)** does agentic COMPLIANCE — flags missing
  disclosures, checks content against approved sources. Content compliance, not
  composition-honesty of an agent's own work claim.
- **Qodo ($70M)** reviews the diff. **Langfuse / AgentOps** score the trace. None is built
  to catch "every number true, the whole a lie."

White-space claim provenance (honest): "nobody productizes composition-honesty" is a
**Fable market scan, Aug 2026** — an informed negative, not a web-verified fact. An absence
cannot be cited the way a funding round can.

**The harder-to-copy moat is authorship-to-outcome.** Separating the ~5% of `type:user`
records a human actually typed from the ~95% of injected noise is the hard part of the whole
category, and it compounds: every week of sessions makes the next answer better, and a
competitor starting in January has no history. That corpus cannot be bought
(`CONTEXT.md:16-29`).

## 5 · The ambitious vision

**The governance layer for an autonomous workforce — the record of what its human drivers
did and whether the work survived.** GEAP-style platforms govern the agents; nothing governs
the prompts or the humans behind them. Transcripto is the system of record for practice:

- Stage 0 — free gate, MIT, one repo in five minutes. The first caught-lie screenshot is the
  growth loop (same shape as "AI deleted my prod DB").
- Stage 1 — the team record: which agents/engineers ship claims that SURVIVE (shipped and
  stayed vs reverted), an append-only audit of every blocked claim, cross-repo. Propagation
  becomes one feature, not the product.
- Stage 2 — the compliance artifact: "prove no agent shipped to production unverified" for
  SOC2 / EU AI Act. The audit log is what a security team hands an auditor.

The end state: no agent's work counts anywhere in an org until it passes the gate, and the
best human prompt propagates itself across every team from the org's own corpus.

## 7 · Honest gaps (do not inflate)

- **Adjacency is lexical shape-matching, not meaning** (`adjacency.py:38-45`). On the real
  corpus it is measured and mostly noise: COUNT-DISAGREES ran over ~4,775 real reports at
  ~21% precision (was ~8% before the plural-noun fix); PARTS-DO-NOT-SUM had 2 documented
  false positives. The other two shapes' real-corpus precision is **UNMEASURED**. So the
  honest line is "measured, mostly noise, two shapes unmeasured" — never "accurate."
- **The moat number is three different figures — never conflate them.**
  - **4.9% human** (95.1% not) — FLEET scale, 537 prompts vs 10,866 records, one 3-day
    window (`PITCH.md:59,73`).
  - **7.1% human** (1,138 of 16,078) — a different, machine-wide run (`PITCH.md:73`).
  - **~46% not-human** — a SINGLE-TERMINAL day (`PITCH.md:59`; MEMORY: "46% of type:user
    turns are NOT Oscar").
  The number is a function of fleet size AND window. Quoting the fleet-scale 4.9% as if it
  were the solo-scale 46% (or vice-versa) is the exact composition error this product exists
  to catch. Pin each figure to its measurement or say `unverified`.
- **The cascade's 13/13 is precision on the kept set, not accuracy.** It is honest only
  paired with coverage (13/24, ~54% decided deterministically) and the held-out lift
  (5/8 vs 3/8). On a 24-item frozen corpus, small-n; the confident set being never-wrong is
  a structural claim, not a large-sample guarantee.
- **Zero non-Oscar users.** The wedge is built and unused; retention (not installs) is the
  real question COMPANY.md names, and it is untested.
- **The white-space claim is a Fable negative, not verified.** Composition-honesty being
  unowned is an informed scan result; the funded-adjacency facts (Zenity, Norm Ai) are
  web-verified.
