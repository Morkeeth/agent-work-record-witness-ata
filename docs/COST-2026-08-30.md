Every metered dimension sits inside the Always Free tier, so the expected charge for
this service is zero. **That is a computation from measured usage against a published
price card, not a figure read from the billing console.** No agent on this project has
read the billing console; if you want the invoice number rather than the derivation,
read it at `console.cloud.google.com/billing` for project `hack-fleet`.

## The number that does not flatter us

827,401 document reads against 78 writes and 14,480 requests is roughly **57 document
reads per request**. The audit view reads the whole collection on each load rather than
paging it. At this traffic it is free and nobody notices. At any real adoption it is
both a bill and a latency problem, and it is the first thing to fix after the event —
before per-agent identity, before the GitHub App.

We are stating it here because a cost table that only shows headroom is the flattering
half. The read amplification is the part a reviewer would find.
