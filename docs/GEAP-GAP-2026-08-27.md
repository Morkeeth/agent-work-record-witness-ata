### F2 — `gemini_same_count` is not a Gemini number, and it is already on a judge-facing surface

`fleet/task_class.py:20` — when `~/.config/keys/gemini.key` is absent, `classify()` silently falls back to a substring heuristic. The `Dockerfile` does `COPY . .`; that key lives outside the repo and there is no secret mount or env var for it. **The container always takes the fallback.**

Reproduced with `HOME` pointed at an empty directory (container conditions):

```
classify("Refactor the auth module...", "bake a chocolate cake with almonds") -> SAME
classify("deploy the kubernetes cluster", "write a haiku about herons")       -> SAME
classify("aaa bbb ccc", "xxx yyy zzz")                                        -> SAME
classify("one two", "three four")                                             -> SAME
```

**The fallback cannot return DIFFERENT.** It gathers terms from *both* prompts, then asks whether any term appears in a and any in b — which is true for any pair of non-empty strings. The value it feeds is named `gemini_same_count`, it is rendered into `surface/org-proof.html`, and on the live service it is a constant equal to the field size. A red light that has never been watched go red. Docstring integrity note: `same_task_class` says *"True when Gemini (or legacy fallback) says SAME"* — the honest reading is that the fallback says SAME unconditionally.

### F3 — The ADK agent is constructed and never invoked

No `Runner`, `run_async`, `InvocationContext` or `generate_content` appears anywhere in `cloud/` or `fleet/`. `cloud/service.py` calls `_agent()` and records `type(a).__module__ + "." + type(a).__name__` into the response and into `/health`. `/health` therefore advertises `"agent": "google.adk.agents.llm_agent.LlmAgent"` while **no model inference happens in the serving path**. The class is real; the reasoning is not.
